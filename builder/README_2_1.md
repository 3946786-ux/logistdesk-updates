# LogistDesk 2.1.0-alpha.1 — обмен между рабочим и домашним ПК

> Разработка: НЕ заменяет действующую 2.0.1 и НЕ публикуется в `latest.json`
> до завершения полной миграции и Windows QA.

## Подтверждённая модель

- **Дом**: полный локальный справочник контрагентов, водителей, машин и документов.
- **Работа**: рейсы, звонки, автоконтроль, напоминания и записи машин; без автоматического
  создания полных карточек в справочнике из каждого звонка после выбора режима «Работа».
- **Кнопка**: строго «Перенести контрагента». Переносит одну выбранную карточку,
  не всю базу; исключает поля паспорта, ВУ, СТС и вложенные сканы.
- **Рабочий поиск**: домашнее приложение публикует отдельный зашифрованный
  минимальный индекс (название, ИНН, телефон, тип кузова, ранее встречавшиеся направления).
  Дома основной справочник, на работе индекс расшифровывается в оперативную память и
  позволяет открыть карточку звонка для выбранного рейса.
- **Рейсы / звонки / автоконтроль / напоминания / история этапов**: двухсторонний
  зашифрованный журнал событий. Локальные номера рейсов и звонков переводятся
  через постоянные UUID-связки. Конфликты редактирования записываются,
  локальные данные не перезаписываются автоматически.
- **Без интернета**: оба клиента продолжают работать локально. Файлы изменений
  попадают на другой ПК после восстановления внешней синхронизации папки.
- **PIN**: прежний, уникальный для каждого ПК. Пароль обмена отдельный,
  минимум 12 символов; не сохраняется в настройках и нужен при запуске обмена.

## Как включать

1. На двух компьютерах нужна одна и та же папка, синхронизируемая одобренным
   пользователем/организацией облачным клиентом (например, корпоративным OneDrive
   или личным сервисом, если разрешён). Сам LogistDesk 2.1 облачный аккаунт
   не создаёт, интернет-API и передачу данных в GitHub не использует.
2. В разделе «Контрагенты» → «Связать компьютеры», выбрать «Работа» или «Дом»,
   свою папку и **одинаковую** отдельную парольную фразу на обоих ПК.
   Роль сохраняется в зашифрованной локальной базе, пароль — нет.
3. В режиме «Дом» после включения формируется зашифрованный поисковый индекс.
4. В режиме «Работа» выбрать контрагента → «Перенести контрагента».
   В режиме «Дом» открыть «Входящие контрагенты» и подтвердить импорт.
5. Рейсы и звонки синхронизируются автоматически порциями по 12 записей
   каждые 30 секунд (пока LogistDesk открыт), также доступна ручная кнопка.
   Пакеты зашифрованы AES-GCM со случайными salt/nonce и scrypt.
   Пароли / полные базы / документы не копируются в общий каталог.

## До реального применения — критические ограничения alpha

- **Ещё нельзя использовать для переноса действующей рабочей базы.**
  Нужна полноценная проверка на двух настоящих Windows ПК с копиями данных.
- **Тестовый EXE `app21_preview.py` принудительно использует отдельный профиль
  `%LOCALAPPDATA%\\LogistDesk21Preview`** — ни в коем случае не существующую
  рабочую/домашнюю базу `%LOCALAPPDATA%\\LogistDesk`. Для теста запускай
  именно сборку из `app21_preview.py`, а не обычную сборку `app20.py`.
- Журнал конфликтов пока сохраняет столкновения для дальнейшей сверки,
  но ещё нет полного UI разрешения конфликтов.
- Жёсткое удаление звонка не синхронизируется как удаление на другом устройстве:
  пока действуют только обновления и добавления. Рейсы с мягким удалением
  передают состояние корзины через `deleted_at`.
- Если на двух устройствах раньше независимо велись одинаковые рейсы,
  одинаковые номера **не сливаются автоматически** во избежание потери данных.
  Создаются отдельные записи (например, R001 и R002) — перед включением
  реального обмена потребуется согласовать первоначальное сопоставление.
- Нужна дополнительная проверка всех вариантов изменения автоконтроля,
  сохранения локальных документов и отказов облачного сервиса.
- Поисковый индекс содержит ИНН/телефоны в **зашифрованном виде**:
  публиковать его можно только с соблюдением требований работодателя,
  прав на использование данных и применимых правил обработки персональных данных.

## Безопасность стабильной версии

Изменения ведутся в `dev/2.1-device-sync`. Релиз 2.0.1 в публичном
`logistdesk-updates` и `latest.json` не изменяется. Резервное
копирование существующей базы производится перед добавлением таблиц
синхронизации. Продолжать тестирование на **копиях** данных.
