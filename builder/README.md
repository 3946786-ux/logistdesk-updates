# Public LogistDesk 2.0.1 build snapshot

This is a standalone source **snapshot**, not a mirror of the private development repository.
It includes application code and synthetic regression tests required for a clean Windows build.
No local profiles, SQLite databases, encrypted customer records, PIN files, drivers' ID documents,
or private repository commit history are copied here.

The original application artwork is recovered from the existing public 2.0.0 executable by
`extract_assets.py`, not from the private Git repository.

**No open-source redistribution license is granted by publication of these source files.**
The desktop program and its user data remain separate. The public runner uses only this snapshot
and its own repository's built-in GitHub token, without any private-repository credential.
